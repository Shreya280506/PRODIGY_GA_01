# ✨ AI Text Generation using GPT-2

## Generative AI Text Generation with GPT-2

This project is a Generative AI application that uses the **GPT-2 language model** to generate human-like text based on a user-provided prompt.

The application was developed using **Python, Hugging Face Transformers, PyTorch, and Streamlit** and provides an interactive web interface for generating creative text.

---

## 🚀 Project Overview

Text generation is one of the important applications of Generative AI.

In this project, a **GPT-2 model** is used to understand a given text prompt and generate a continuation based on the patterns learned during training.

The overall workflow is:

```text
User Prompt
     │
     ▼
GPT-2 Tokenizer
     │
     ▼
GPT-2 Language Model
     │
     ▼
Generated Text
     │
     ▼
Streamlit Interface
